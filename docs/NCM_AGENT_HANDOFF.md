## Objective and essential limits

Improve exact reconstruction and compilation of C# with the NCM codec, aiming toward 99–100% token accuracy and 48/48 stress compilation; the eventual goal is a useful coding generator. The user explicitly wants to retain the 64-level representation for accuracy while exploring improvements. A codec round trip encodes the **known original**; it does not prove that a generator can create the code. Compilation is not behavioral correctness. Do not claim the NCM is faster, cheaper, or more accurate than an LLM without an end-to-end matched measurement.

The current 64-level codec uses 8,194 indices per 256-token input chunk; fixed-width VQ+corrections was around 83x input bytes on short stress samples. An exact correction sidecar can restore known input, but requires target-derived data and does not solve unknown-target generation. Lossless zlib beat that VQ representation in prior storage checks. Encoder-side index search also needs the known original to choose indices and was marginal. Latent adapters add parameters/decode compute without reducing the index count.

## What has not worked reliably

The fresh-codec improvements from a larger codebook, longer training, several identifier/repetition/literal/comment weights, deeper/wider models, multi-pass repairs, candidate rankers, repeated VQ index searches, a third codec, separate-checkpoint ensemble students, and a continuous-path teacher were mixed, weak, or regressed under the individual tests. The precise records and qualifications are in the experiment history. Adding self-attention to the latent adapter tied the original adapter on exact counts; latent-only training and padding-masked MSE did not improve it; an ensemble-guided frozen adapter was also slightly worse. The literal-name placeholder screen badly regressed with the frozen codec. Avoid repeating these ideas without a new, testable reason.

The continuous-encoder diagnostic improved known-input reconstruction from **218 to 258/348 exact** for the original codec; passing continuous vectors directly is not a discrete codec, a theoretical upper bound, or a generator. More weight on final VQ loss did not improve the subsequent discrete run. Differences in training data composition and length, sample order and effective epochs complicate causal claims.
